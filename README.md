# 🎨 Products Frontend

## 📌 Overview
Web application for managing `Product` entities through a REST API.  
Provides a dynamic user experience using AJAX without full page reloads.

---

## 🏗️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- AJAX (XMLHttpRequest / Fetch API)

---

## 🚀 Features
- Display list of products dynamically
- Create new products
- Edit existing products
- Delete products
- Real-time UI updates without page reload
- Modal popups for user interactions

---

## 🔗 API Integration

This frontend communicates with the backend API:

- `GET /api/products`
- `POST /api/products`
- `PUT /api/products/{id}`
- `DELETE /api/products/{id}`

---

## ⚡ User Experience
- Dynamic DOM updates
- No full page reloads
- Popup modals for:
  - Create
  - Edit
  - Delete confirmation
- Immediate feedback after actions

---

## 🧠 Technical Decisions
- AJAX used to improve performance and UX
- Separation between UI logic and API calls
- Modular JavaScript structure

---

## ⚙️ Features

- Automatic product price calculation
- Data validation

## 🧠 Technical Highlights
