# 🧾 Product Management App

## 📌 Overview
Web application to manage products, including CRUD operations and automatic price calculation.

## 🚀 Tech Stack
- Frontend: (React / Razor / etc)
- Backend: .NET Core 3.1
- Database: SQL Server
- Other: Entity Framework, AutoMapper

## ⚙️ Features
- Create, update, delete products
- Automatic product price calculation
- Data validation

## 🧠 Technical Highlights
- Clean architecture
- REST API design
- Separation of concerns

## ▶️ How to Run
1. Clone repo
2. Run backend
3. Run frontend
